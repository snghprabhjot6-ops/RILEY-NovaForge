# Changelog

## 0.2.0 — 2026-11-27

- Add the Riley graphical local app with NovaForge branding, responsive layout, light/dark themes, preferences and accessible controls.
- Add SQLite conversations, export, confirmed deletion, draft-preserving failures and busy-state handling.
- Add local Ollama AI conversations alongside the built-in and echo backends.
- Add browser speech synthesis and opt-in dictation, with language and voice selection.
- Add double-click Windows/macOS source launchers, package metadata and a Windows executable build workflow.
- Separate optional CLI audio dependencies from the minimal runtime and developer tools.
- Fix greeting substring matches, reject non-real/non-finite arithmetic results, and avoid storing unanswered CLI turns after backend errors.
- Add HTTP integration, persistence, Ollama and regression tests; update setup/status/security documentation.

## 0.1.0 — 2026-11-26

- Add the modular Python CLI, deterministic multilingual local engine, safe arithmetic, JSON history, configurable optional audio and initial tests.
- Preserve the earlier browser prototype on its existing branch.
