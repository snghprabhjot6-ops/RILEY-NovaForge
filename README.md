# RILEY-NovaForge

A responsive, browser-based starting point for Riley, a multilingual personal assistant.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server, for example:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive interface for desktop and mobile browsers on macOS and Windows.
- Localized interface and demo messages in English, Hindi, French, Bengali, Sanskrit, and Spanish.
- Optional browser speech output and, when supported, speech-to-text input. Riley prefers a voice with a feminine-sounding name when one is available; voice availability and characteristics depend on the browser and installed system voices.
- Local image attachment previews and entry points for coding and vision tasks.

This is a front-end prototype, not a connected AI agent. Chat replies and image analysis are not generated by an AI model; the interface explains this rather than implying it can analyze a picture or solve a coding task. A trusted model service and platform-specific integrations must be configured to provide those capabilities. No messages or uploaded images are sent to a service by this prototype. Browser speech recognition, if enabled, may use the browser or operating system’s own speech service; check its privacy settings.
